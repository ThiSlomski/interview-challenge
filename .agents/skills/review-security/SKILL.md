Entrada: Pergunta de revisão, fontes e critérios; nenhuma conclusão esperada.

Procedimento: Revise em leitura por padrão. Mapeie fronteiras e dados; use README itens 2, 5–10 e Parte 4. Classifique achados por impacto com arquivo e evidência. Diferencie recurso ausente de vulnerabilidade comprovada. Não execute ataques externos nem leia segredos. Pare após a análise delimitada; correções só com tarefa atribuída.

Saída: Achados, lacunas de testes e nova verificação necessária.
