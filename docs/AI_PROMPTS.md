# Log de prompts de AI

> O uso de AI é **permitido e incentivado** neste desafio. Registre aqui os
> prompts relevantes que você usou e, principalmente, seu **julgamento crítico**
> sobre o que a AI gerou. Avaliamos o uso responsável — não copiar/colar cego.
>
> Não precisa registrar cada autocomplete trivial; registre o que influenciou
> decisões de arquitetura, segurança, código ou documentação.

## Ferramentas usadas

_Ex.: Cursor, Claude Code, GitHub Copilot, Amazon Q, ChatGPT — e para quê._

> Copie o bloco abaixo para cada prompt relevante.
