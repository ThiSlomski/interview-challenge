# Contrato de tarefa

Consumidores: orquestrador e skills plan-requirement / verify-delivery.
Preencha antes de criar instância; use também para trabalho sequencial.

```text
ID / requisitos:
Papel / ganho esperado da delegação:
Objetivo / escopo / exclusões:
Fontes e entradas selecionadas:
Dependências / contratos compartilhados:
Escrita atribuída (nenhuma em revisão):
Aceite / verificações / destino de evidência:
Tempo / uma execução + até duas correções / parada:
Contexto herdado ou selecionado / limite de concorrência:
Retorno: instância e skill realmente usada; arquivos lidos/alterados;
decisões; comandos e resultados; achados; riscos; pendências; próximo passo.
```

Em conflito suspenda a escrita, preserve ambos os trabalhos e peça integração
ao orquestrador. Documentação consolida arquivos compartilhados após os retornos.
Não faça Git mutável em paralelo. Quem revisa recebe pergunta, fontes e aceite,
sem a resposta esperada. Sem subagentes, identifique autorrevisão sequencial.
